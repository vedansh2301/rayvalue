東京都の令和8年度（2026年度）の助成では、既存住宅に太陽光発電を設置すると1kWあたり15万円（3.75kW以下、上限45万円）、蓄電池は1kWhあたり10万円（上限120万円）が出ます。事前申込は2026年5月29日に始まっており、原則として契約の前に申し込む必要があります。今年度からは銀行振込などの記録が必須になり、現金で支払った取引は対象外です。

## 押さえておきたい数字（2026年11月22日確認）

- **15万円/kW（上限45万円）**：既存住宅、3.75kW以下の太陽光。3.75kW超は12万円/kW（[東京都環境局、令和8年4月版](https://www.kankyo.metro.tokyo.lg.jp/documents/d/kankyo/2026-06-29-095330-861)）。
- **12万円/kW（上限36万円）**：新築住宅、3.6kW以下の太陽光。3.6kW超は10万円/kW。
- **10万円/kWh（上限120万円/戸）**：蓄電池の新設（DR実証に参加しない場合）。
- **+10万円/件**：蓄電池の新設や増設時にDR実証へ参加した場合の上乗せ。
- **2026年5月29日**：令和8年度の事前申込の受付開始日。
- **約1,012億円**：断熱・太陽光住宅の事業全体の予算規模（[東京都環境局](https://www.kankyo.metro.tokyo.lg.jp/documents/d/kankyo/2026-05-22-172029-052)）。

## 東京都の太陽光補助金はいくら？

令和8年度の「家庭における太陽光発電導入促進事業」の助成額は次のとおりです。

| 区分 | 容量 | 助成額 |
|---|---|---|
| 既存住宅 | 3.75kW以下 | 15万円/kW（上限45万円） |
| 既存住宅 | 3.75kW超 | 12万円/kW（50kW未満） |
| 新築住宅 | 3.6kW以下 | 12万円/kW（上限36万円） |
| 新築住宅 | 3.6kW超 | 10万円/kW（50kW未満） |
| 機能性PVへの上乗せ | | 区分に応じて10万円、8万円、5万円、2万円、1万円/kW |
| 陸屋根の住宅への上乗せ（既存戸建の架台設置） | | 10万円/kW |
| パワーコンディショナ更新 | | 費用の1/2（上限10万円/台） |

機能性PVとは、軽量や小型、建材一体型など、通常のパネルを置きにくい屋根向けの製品です。都は令和8年度にこの区分を拡充しました。

**計算例**：既存住宅に3.5kWを設置すると、15万円×3.5kW＝52.5万円ですが、上限があるので45万円です。4kWを設置すると、3.75kW超の区分になり12万円×4kW＝48万円です。容量の境目で金額が逆転することがあるので、見積もりの段階で確認しましょう。

## 東京都の蓄電池補助金はいくら？

| 項目 | 助成額 | 主な条件 |
|---|---|---|
| 蓄電池システムの新設 | 10万円/kWh（DR実証不参加なら上限120万円/戸） | 太陽光が設置済みか同時設置。太陽光がない場合は再エネ電力メニューの契約 |
| 既存蓄電池のユニット増設 | 6万円/kWh（DR実証不参加なら上限72万円/戸） | 太陽光が設置済み |
| DR実証参加の上乗せ | +10万円/件 | 新設または増設時にDR実証へ参加 |
| DR実証用のIoT機器 | 5万円/台 | DR実証参加に伴う設置 |
| V2H | 費用の1/2（上限50万円） | 太陽光、EV/PHV、V2Hがそろう場合は10/10（上限100万円） |

都の資料によると、令和8年度は蓄電池の単価を見直し、上限額を設けました。

国のDR家庭用蓄電池補助金（SII）は2026年5月29日に予算に達して締め切られ、再開の予定はありません。2026年11月時点で、東京都の助成は家庭用蓄電池の大きな支援策として残っています。

## 申請の流れは？

都の資料が示す流れは次のとおりです。

1. **事前申込**（見積書と本人確認書類が必要）
2. 契約締結
3. 設置工事
4. 設置と支払いの完了
5. **交付申請兼実績報告**
6. 審査、交付

最も大事なのは**契約の前に事前申込をすること**です。特例として、2026年4月1日から6月30日の間に事前申込の前に契約や工事をした場合は、要件を満たし2027年3月31日までに申し込めば対象になります。

## 現金払いは対象外。支払い方法に注意

令和8年度の事前申込分から、実績報告の際に「金融機関発行の証明書等」の提出が必須になりました。「現金の受け渡し」による取引は助成の対象外です。

認められる証明の例は、ローン契約明細書、ATMや窓口での振込明細、ネットバンキングの振込履歴、クレジットカードや電子マネーの利用明細です。訪問販売で「現金なら値引きする」と言われても、助成を受けられなくなるので応じないでください。訪問販売の注意点は[訪問販売のトラブルと注意点](/jp/guides/homon-hanbai-trouble)にまとめています。

## 初期費用ゼロ（リース・PPA）にも補助がある

自分で買わずに、事業者が設置して月額料金で使う「初期費用ゼロ」サービスにも別の助成があります。既存住宅は3kW以下で18万円/kW、3kW超で12万円/kW、蓄電池は一律10万円/kWh（上限120万円）です（[東京都、2026年2月18日](https://www.metro.tokyo.lg.jp/information/press/2026/02/2026021809)）。助成金はサービス事業者に支払われ、料金の引き下げなどを通じて利用者に還元される仕組みです。

## 区の補助金と組み合わせると？

都の資料は、国や区市町村の補助金も合わせて利用できると案内しています。区によって内容は大きく違います。

| 区 | 太陽光 | 蓄電池 | 受付状況 |
|---|---|---|---|
| 杉並区 | 4万円/kW（上限12万円） | 定額5万円（3kWh以上） | 受付期間は2026年4月10日〜2027年2月26日、11月10日時点の申込率55.08% |
| 足立区 | 6万円/kW（上限24万円、区内事業者なら7.2万円/kW） | 上限5万円（区内事業者なら6万円） | 11月16日時点で第3期受付中、第4期は2027年1月4日〜2月26日 |
| 練馬区 | 定額8万円（既存住宅） | 区のメニューなし | 追加受付は2026年12月1日〜2027年1月29日（予算4,000万円） |

**例**：杉並区の既存住宅に3.5kWの太陽光を付ける場合、都の45万円に区の12万円を加えて57万円です。経済産業省の2025年の平均費用28.9万円/kW（税抜、新築）で3.5kW分を計算すると約101万円なので、半分以上を補助でまかなえる計算です（[調達価格等算定委員会](https://web.archive.org/web/20260611114949/https://www.meti.go.jp/shingikai/santeii/pdf/20260205_1.pdf)）。回収期間の考え方は[太陽光発電は2026年に元が取れるか](/jp/guides/taiyoko-motogatoreru-2026)をご覧ください。

## 申請前のチェックリスト

- 契約前に事前申込を済ませたか
- 支払いは振込、ローン、カードなど記録が残る方法か
- 太陽光の容量が補助の境目（既存3.75kW、新築3.6kW）のどちら側か
- 蓄電池の容量と上限120万円の関係を確認したか
- 区の補助金の受付期間と予算残りを確認したか

*RayValue（民間）による解説です。東京都やクール・ネット東京の公式情報ではありません。申請は必ず公式の手引きを確認してください。*
